## 3. 見つかった不具合と直し（この通しで直したもの）

as-is 側（前半。コミット 12e21bb ほか）:
- 照合シート（make_compare）が本物の PNG の無い環境で止まる → 下見の PNG を使う。
- PowerPoint の図だけのスライド（文の無い手順）を、フロー化の下書きが拾えない → 図の箱を線でたどって項目にする（draft_flow）。図の箱を出典に引けるようにした（apply_edits）。
- 採否表の `action` を足したら全部の箱が「変わった」と出る → あとから足した項目を比べない（review.py）。
- 分けた箱への確認事項・判断の担当・つなぐ線の担当など、編集の細かな不具合（apply_edits）。
- 保育所の資料で、長いフローの終了の図形がスライドの外に出ていた（試験の資料の作り方。make_fixture_welfare）。

拠点間比較側（後半）:
- **記載なしの候補が重なる**: 共通の資料の手順は、拠点のフロー何本かで「外した項目」に載るので、候補に同じ手順が 2〜3 回並び、本当の候補を押し出していた。1 回だけ出し、ほかのフローで描いた項目は出さない（sc_match）。直したら隠れていた候補が 15 か所で出て、担当に確かめ直させた。
- **照合シートの読み違い**: 表の資料では札・帳票・補足が引用（手順の列）に出ないため、照合の担当が「引用から読めない」と何度も指摘した。担当・システム・帳票・順序の差を機械が出すことも知らされず、内容の差に足すよう求めた。前書きに 2 文を足し、帳票の受け・出しの重なりを除いた（sc_verify）。
- **内容の差を足して直した指摘を「反映していない」と止める**: 同じタスクに新しい内容の差があれば、反映したとみなす（sc_check）。
- **照合シートを出したあとも「照合をしていない（シートを出す）」と出る**: シートを出したか・報告が届いたかで、次の手を変える（sc_check・sc_status）。
- **出典のセル番地を行の ID と読み違える**: 「「収納事務」シート B10」の B10 を、行の ID の漏れとして納品物の点検が止めていた。出典の表示を除いてから探す（sc_check）。
- **支持率の丸め**: 94.7% を「95%（95% 未満）」と出していた。切り捨てて小数 1 桁（sc_check・sc_book・sc_deliver・asis の check_flow）。
- **対象外の行の区分**: ほかの拠点が対象外の行で、1 拠点だけの作業を「共通」（緑）にしていた（決まり 5.2 と食い違い）。拠点固有にした（sc_compute）。
- **図**: 対象外の拠点のレーンの見出しが「（記載なし）」で凡例にも無い → 「（対象外）」と凡例。内訳の枠のラベルに上から入る矢印が重なる → ラベルを短く。特養と保育所の見出しが同じ色で続き、拠点の境が分からない → 塊の境に太い線（sc_drawio）。
- 消したタスクの番号が飛ぶ → はじめて納品する前なので、決まり 7.6 どおり `sc_compute.py --renumber` で振り直した（道具の直しではない）。

## 4. まだ直していないこと（決まりの足りない所）

1. **ほかの拠点が行う作業の箱**: 特養は本部が行う支払・給与計算を「本部拠点」レーンの箱に描き、保育所は箱の補足に書いた。比較では特養 ○・保育所 — になり、作業の差に見える。照合の担当も 2 回指摘した（保留）。決まりに「担当がほかの拠点の箱は、その拠点の作業ではない（記号を分ける・記載なしと同じに扱う）」が要る。保育所の「本部の固定資産管理責任者」も、本部の固定資産管理責任者と同じ組にするかの決まりが要る。
2. **書き分けで行わないと分かっている記載なし**: 当初予算編成の予算案の作成〜確定は、共通の資料が「本部だけ」と書いているのに、特養・保育所の「記載なし」として追加の資料の依頼の上位に出る。書き分けで説明のつく記載なしは、依頼から外すか別に分けたい。
3. **内容の差の根拠に、共通の資料の書き分けを引けない**: 根拠は箱しか指せない。小口現金（本部が保育所の分も払う）のように、書き分けが根拠のときは照合の担当が「引用に無い」と読む。
4. **配置**: 線の並走・交差（判断から戻る線と次の線が近い所）、1 つの塊に終了が 2 つある所、10 レーンのページの幅（約 3200px）。1 文字だけ次の行に落ちる折り返し。どれも FAIL・WARN にはならない。
5. **レーンの見出しの名前**: 特養の塊でも、用語の組の名前（出納職員）が出る。特養の資料では「事務員」なので、「出納職員（事務員）」のように拠点の言葉を添えたい。
6. **as-is の 1 つの箱が 2 つの作業を書いているとき**（本部の「予算要求書、事業計画および社会福祉充実計画を収集する」）、比較の段では分けられない。照合の担当 2 人とも一部支持で、確認事項にした。
