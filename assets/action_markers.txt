# 補足（注記・ただし書き・囲み・表の欄外）の中に書かれた「作業」を機械で拾うための目印。check_extract.py が使う。
# 資料の書きぶりに合わせて足し引きしてよい（行頭の # はコメント）。
#
# 候補にする文 = 補足の目印がある文（[anywhere] が文の中にある／[at_start] で文が始まる／[heading] だけの行か [heading] で終わる短い見出し
#               （「支払の手続きの注意事項」）のすぐ後の文）のうち、[action] に当たり、[not_action] に当たらないもの。
#               読み手に頼む言い回し（[directive]。「〜してください」「〜しましょう」「〜することが必要です」）の文は、目印が無くても
#               候補にする（囲みの見出しが画像で、文字としては目印が取れないことがある）。[not_directive]（「〜を参照ください」）は除く。
# 候補は、カードの手順（steps）・分岐（decisions）の引用に入っているか、notes に why_not_action（作業でない理由）つきで
# 書かれていなければ FAIL になる。機械的な当たりなので、作業かどうかは読取の担当が1件ずつ決める。
# [anywhere]・[at_start]・[heading] は文字そのまま、[action]・[not_action] は正規表現（空白を落とした文に当てる）。
# 「る」で終わる作業（確かめる・入れる・送る）は [action] で拾い、状態・可能・受け身・決まりの言い回し（ある・なる・できる・される・とする）は [not_action] で外す。
